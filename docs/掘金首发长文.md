# 我把一个传统后台，变成了 AI 智能体的工具箱（已和 WorkBuddy 打通）

> 副标题：一个「平台无业务、全插件化」的后端框架，顺手治好了我的微服务 PTSD

---

## 0. 先说结论

我做了一个后端框架 **SSA Service**：它的内核**没有任何业务**，所有能力都来自「动态插件 JAR」。你写一份 SQL YML 就得到一个接口，末尾加一行 `mcptool:true`，这个接口**自动变成 AI 智能体（WorkBuddy 等）能调用的工具**。

同一套插件代码，还能在**单体 / 嵌入式 / 微服务**三种形态间零改动切换 —— 我管这叫 **一体多态 · Fluid Topology**。

## 1. 这事得从「微服务踩坑」说起

2019 年我转 Java，接手了一套底层用 JFinal 的系统。里面**全是写死的 SQL**，加个字段、改个字段都是灾难。我维护了俩月就开始琢磨：怎么让自己轻松点？于是把 SQL 写成模板放到外面热加载 —— 小问题谁都能改，改好告诉我我来合并。

同年下半年微服务大火，火到不用就好像落后了。我也没忍住，找前大厂同事搭了一套微服务架构，兴冲冲拆出好几个服务。结果客户只给 **1~2 台服务器**：数据库、Redis、Nacos 一跑，资源就没了；所有微服务跑起来就是灾难，日志满天飞还不好查。

那一刻我明白：**微服务不是银弹，轻量才是大多数项目的真相。**

于是我边做业务边写出了插件机制，把 ActiveRecord 搬进来，慢慢形成内核：`sql-api` + `method-api`。后来全公司大规模用上了。

## 2. 平台无业务，一切皆插件

传统 Spring Boot 脚手架把 Controller/Service 写死在主工程；SSA 的主工程是个**空壳运行时**，业务 100% 在插件 JAR 里。需要什么能力挂什么插件，不需要就卸载，**平台永远不碰业务逻辑**。

自研的 `SpringMvcPluginClassLoader`（继承 `URLClassLoader`）在运行时扫描插件 jar，把标注类注册成 Spring Bean、按 `routePrefix` 挂路由；支持 `enablePlugin/disablePlugin` **运行时热启停**，坏插件不拖垮启动。

### 写一份 YML，就有一个接口

```yaml
# user/list.yml
key: user-list
datasource: main
content: |
  SELECT id, name, email FROM ssa_user
  WHERE status = #{status}
params2:
  - name: status
    type: int
    required: 1
    hint: 用户状态 1=启用 0=禁用
returnType: list
```

调用：`POST /sqlApi/v1/user/list` 即可。不用写 Controller、不用写 Service。

### 注解即 API，且能覆盖 YML（MethodApi）

```java
@SsaApiClass("report")
public class ReportApi {
    @SsaApiMethod(name = "profit")   // 注册名 report.profit，同名时覆盖 sql-api
    public Object profit(Map params) { /* 复杂逻辑写这里 */ return ...; }
}
```

先用 YML 跑通 80% 场景，复杂逻辑写个同名方法无缝覆盖 —— 我管这叫「代码级逃生舱」。

## 3. 重点来了：加一行，接口变 AI 工具

在 YML 末尾加一行：

```yaml
mcptool: true
```

平台基于官方 MCP Java SDK 2.x（Streamable HTTP）**自动扫描** ymlapi 目录，把这个接口注册成 MCP 工具，JSON Schema 由参数自动生成；`POST /mcp/rescan` 热刷新。工具调用走**同进程 ApiRunner，零网络跳**。

这意味着什么？你原来在管理后台里一个个点的操作 ——「把 X 客户的账期改到 90 天」「导出发票台账发给财务」—— 现在智能体直接用自然语言就能驱动：

> 「把 X 客户的账期改到 90 天」→ 智能体调 `mcptool` 工具 → 同进程执行 SQL → 完成。

**一套声明，前端 / CLI / Agent 三端复用。** 你的传统后台，瞬间装上了一套 Agent 可调用工具箱，业务零重写，AI-ready 即插即用。这也是它已经与 **WorkBuddy** 打通的实战路径。

更妙的是：sql-api 的前后置事件能 `ApiRunner.safeRun` 调其它接口；当这些接口被标成 MCP 工具，AI 不仅能查数据，还能在工具链里触发审批、推送、导入 —— 「数据接口」与「AI 工具」是同一份声明，两条链路共享一套引擎。

## 4. 一体多态 · Fluid Topology

同一套插件 JAR，在三种形态间零改动切换：

- ① 单体 `ssa-ser`（单 JAR，起步）
- ② 嵌入式 `ssa-ser-client`（塞进桌面 / 内网一体机）
- ③ 微服务 `ssa-msa`（Gateway + Nacos + N×ssa-ser，扩容）

小项目单 JAR 起步，业务涨了加网关注册多实例即可水平扩展。就像水没有固定形状，却能装进任何容器。
