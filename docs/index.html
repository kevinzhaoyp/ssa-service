开源后端框架 · Java 17 + Spring Boot

SSA Service
平台无业务，一切皆插件

一套内核 + 动态插件 JAR，让你用「写 SQL / 写 YML」的方式生成接口； 一行 mcptool:true 把任意接口变成 AI 智能体工具；同一套代码在单体、微服务、嵌入式之间自由伸缩——我们称之为 一体多态 · Fluid Topology。

🔌 全插件化运行时 📝 SQL 即 API 🤖 MCP 工具动态注册 🧩 单体 / 微服务 / 嵌入式 一体多态 ♻️ 插件热装载 / 热卸载 ⚡ 传统后台秒变 Agent 工具箱

01一句话定位

它不是又一个「业务脚手架」，而是一个没有业务的后端运行平台。

SSA Service 把「接口能力」从代码里抽离出来，交给插件。 平台内核只负责：接收请求 → 找到插件里的接口 → 执行 → 返回。业务规则写在插件 JAR 里（可以是 Java 类，也可以是一份 SQL YML）， 需要什么能力就挂什么插件，不需要就卸载——平台本身永远不碰业务逻辑。

💡 这正是它区别于传统 Spring Boot 脚手架的地方：传统脚手架把 Controller/Service 写死在主工程里； SSA 的主工程是「空壳运行时」，能力 100% 来自外挂插件，且插件可运行时增删。

02架构总览

内核（无业务） + 插件插槽（有业务） + 三种可流动的部署形态。

03五大亮点

每一项都直接对应一个可落地的开发体验升级。

📝

亮点一 · SQL 即 API（sql-api）

不用写 Controller、不用写 Service。新建一份 YML，写上 SQL 和参数，接口就生成了，自动暴露为 POST /sqlApi/v1/{apiName}。支持多数据源、存储过程、前后置事件链，事件还能反过来调用其它接口， 形成编排能力。业务人员也能参与「造接口」。

🔌

亮点二 · 动态插件 JAR

自研 SpringMvcPluginClassLoader（继承 URLClassLoader）在运行时扫描插件 jar，把其中标注的类 注册成 Spring Bean、把 Controller 按 routePrefix 挂到主路由。支持运行时启停插件 （enablePlugin / disablePlugin）+ API 列表热刷新，坏插件不影响主程序启动。

🤖

亮点三 · MCP 工具动态注册

mcp-api 插件内嵌官方 MCP Java SDK 2.x（Streamable HTTP）。启动时自动扫描 ymlapi 目录， 凡是声明 mcptool: true 的 SQL 接口，一键变身为 AI 智能体的工具；JSON Schema 由参数自动生成； POST /mcp/rescan 可热刷新。工具调用走同进程 ApiRunner，零网络跳。

⚡

亮点四 · 注解即 API，可覆盖 sql-api（MethodApi）

用 @SsaApiClass 标注类、@SsaApiMethod 标注方法，Java 方法直接注册为接口，无需写 Controller； 注册名规则 类前缀.方法名。关键能力：同名 API 时 MethodApi 覆盖 SqlApi——先用 YML 快速声明接口跑通 80% 场景， 遇到 YML 难以表达的复杂逻辑（多表事务、第三方调用、特殊校验），写一个同名 @SsaApiMethod 即可无缝覆盖， 无需改删原 YML。这是声明式体系的「代码级逃生舱」。

🧩

亮点五 · 一体多态部署（Fluid Topology）

同一套插件 JAR，可在「单体 JAR（ssa-ser）」「嵌入式桌面（ssa-ser-client）」「微服务集群（Gateway + Nacos + N×ssa-ser）」 三种形态间自由切换，插件代码零改动。小项目单 JAR 起步，业务涨了加网关注册多实例即可水平扩展。 就像水没有固定形状，却能装进任何容器。

🚀

Bonus · 传统后台秒变 Agent 工具箱

因为每一项能力都已是统一 HTTP API（sql-api + method-api），并在 YML 末追加 mcptool:true 即可注册为 MCP 工具—— 你原来在管理后台里一个个点的操作，瞬间变成智能体（WorkBuddy 等）能用自然语言驱动的工具，也能被命令行 / 脚本直接调。一套声明，前端 / CLI / Agent 三端复用。

04亮点详解 · SQL 即 API + 一行变 MCP 工具

这是「平台无业务、全插件化」与「AI 友好」结合得最妙的地方。

① 写一份 YML，就有一个接口（含参数校验、多数据源、事件）：

# user/list.yml
key: user-list
datasource: main
describe: 查询启用用户
content: |
  SELECT id, name, email FROM ssa_user
  WHERE status = #{status}
  ORDER BY id
params2:
  - name: status
    type: int
    required: 1
    hint: 用户状态 1=启用 0=禁用
returnType: list

② 加一行 mcptool: true，它自动成为 MCP 工具：

# 在同一份 yml 末尾追加一行
mcptool: true

③ MCP 客户端（WorkBuddy / Claude 等）连接 POST /mcp，tools/list 即可发现 user_list 工具； tools/call 时平台在同进程内执行该 SQL 并返回——无需任何额外胶水代码。

# 热刷新，注册新工具无需重启
POST /mcp/rescan
→ notifyToolsListChanged() 通知已连客户端
🔗 完美结合点： sql-api 的「前后置事件」可以调用 ApiRunner.safeRun 执行任意其它接口； 当这些接口被标记为 MCP 工具后，AI 智能体不仅能查数据，还能在工具链里触发审批、推送、导入等动作—— 「数据接口」与「AI 工具」是同一份声明，两条链路共享一套执行引擎。MethodApi 的同名覆盖能力，则让你在「声明式 YML」与「命令式 Java」之间自由切换，互不打架。

05传统后台，秒变 Agent 工具箱（CLI 对接 Agent）

这是「一体多态」之外，最让老系统重获新生的能力。

问题：后台操作困在 UI 里

传统管理后台里，「改个账期」「导一份报表」「发一条通知」都是按钮背后的写死逻辑。 没人点，它就动不了；想让 AI 或脚本去驱动，就得再写一整套对接层。系统越老，越像一座孤岛。

解法：把操作声明成 API，再标 mcptool

在 SSA 里，这些操作只需声明成 sql-api 或 method-api（写 SQL / 写注解即可），末尾加一行 mcptool:true。于是同一批接口：
• 前端页面照常调；
• 命令行 / 脚本 / CI 直接调；
• 智能体（WorkBuddy 等）经 MCP 用自然语言调。

🤖 一句话场景： 不必再打开后台逐个点击——「把 X 客户的账期改到 90 天」「导出发票台账并发给财务」， 智能体直接调用对应的 MCP 工具即可完成。你的传统后台，等于瞬间装上了一套 Agent 可调用工具箱 + CLI 入口， 业务零重写，AI-ready 即插即用。这也是它已经与 WorkBuddy 打通的实战路径。

06一体多态 · Fluid Topology（正式命名）

你提的「灵活的伸缩式服务」概念很准，我们正式把它定名为——

原名：灵活的伸缩式服务
一体多态 · Fluid Topology
One Core, Many Shapes — 一个内核，多种部署形态自由流动

内核与插件不变，部署形态随业务规模「流动」：单机单 JAR（起步）→ 网关后的多实例集群（扩容）→ 或塞进桌面做嵌入式一体机。 就像水没有固定形状，却能装进任何容器。

07技术栈与对比

现代、主流、对企业友好。

技术栈

• Java 17 + Spring Boot（4.x 已验证）
• Spring Security + JWT 鉴权
• 数据库访问：JFinal ActiveRecord（多数据源）
• 微服务：Spring Cloud 2025.1 + Spring Cloud Alibaba + Nacos
• AI：官方 MCP Java SDK 2.x（Streamable HTTP）

🤖

11快速感受

# 1) 构建（JDK 17+、Maven 3.8+）
git clone https://gitee.com/kevinzhaoyp/ssa-service.git
cd ssa-service && mvn clean package -DskipTests

# 2) 进入 client 产物目录，准备插件与模板（jar 同目录即根目录）
cd ssa-ser-client/target
mkdir -p plugins sqlapi
cp ../../ssa-plugins/sql-api/target/sql-api-2.0.0.jar plugins/

# 3) 写第一个 SQL 接口（无需建表）：文件 sqlapi/now.yml
content: SELECT NOW() AS now_time

# 4) 配数据源（文件 application.yml，jar 同目录）
sqlapi:
  datasource:
    main:
      driver-class-name: com.mysql.cj.jdbc.Driver
      url: jdbc:mysql://127.0.0.1:3306/test?useSSL=false&serverTimezone=Asia/Shanghai
      username: root
      password: 你的密码

# 5) 启动（嵌入式形态：无登录、无鉴权，默认端口 8080）
java -jar ssa-ser-client-2.0.0.jar

# 6) 调用（请求体即参数对象，无参传 {}）
curl -X POST http://localhost:8080/sqlApi/v1/now -H 'Content-Type: application/json' -d '{}'

# 7) MethodApi：用注解注册并覆盖同名 SQL 接口
@SsaApiClass("report")
public class ReportApi {
    @SsaApiMethod(name = "profit")   // 注册名 = report.profit，同名时覆盖 sql-api
    public Object profit(Map params) { /* 复杂逻辑写这里 */ return ...; }
}

# 8) AI 智能体接入 MCP（标记 mcptool:true 的接口自动出现）
POST /mcp   →  tools/list   →  tools/call now
📌 ssa-ser-client 为嵌入式形态，默认无登录鉴权，最适合本地尝鲜。插件目录 plugins/ 与 SQL 模板目录 sqlapi/ 默认取运行 jar 所在目录；数据源 key 为 sqlapi.datasource.main.*。完整精确端点以仓库 README 为准。
